========================
Quality Test Management
========================

Allows teams to define quality tests for critical business processes and
track test runs over time. Supports notification rules (time-based and
module-update-based) to prompt the responsible user to re-run a test.

Bug Tracker
===========

Bugs are tracked on `GitHub Issues <https://github.com/CompassionCH/compassion-switzerland/issues>`_.
