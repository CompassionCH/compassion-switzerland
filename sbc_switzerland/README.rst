This module tailors letters import for reading PDFs from the NAS. It
adds option to import letters with import configuration and option to
select multiple letters on import.

It also manage the Swiss translation platform for letters that need
translation

Configuration
=============

Add the following parameters to your Odoo configuration file:

- ``sftp_user``: user for connecting on the NAS of Compassion with Samba
- ``sftp_pwd``: password for Samba
- ``sftp_ip``: IP address of the NAS of Compassion
- ``sftp_port``: Samba port of the NAS

Letter follow-up activities
---------------------------

Three automation rules (Settings > Technical > Automation > Automation
Rules) create a To-Do activity:

- **Sponsorship: no child letter 3 months after start**: no letter from
  the child has reached the sponsor (state "Published to Global
  Partner") 3 months after the start date of an active sponsorship.
- **Sponsorship: no child letter 1 year after start**: the same, 1 year
  after the start date.
- **Letter: stuck in translation for 2 months**: a letter of an active
  sponsorship is in "National Office Translation Queue", "To Translate"
  or "Translation check unsuccessful", and its status has not been
  updated for 2 months.

The rules are installed inactive. To use them, open each rule, set the
"Responsible" of its action, and only then activate the rule. Without a
responsible, the activities go to the default user of the To-Do activity
type, or else to OdooBot, which nobody sees. The responsible also
becomes a follower of each sponsorship or letter that gets an activity.

Only dates that pass after the module installation create activities;
older cases are not flagged. Dates that pass between the installation
and the activation are all flagged at the first run, so activate the
rules on the day of the installation.

Usage
=====

Used by the onramp_compassion module to send an email on reception of a
new child letter.

The letter is sent to the sponsor's email address.
