In developer mode, go to *Settings > Technical > Automation > Server Action
Monitor*, or use the *Executions* button on the form of a server action, a
scheduled action or an automation rule.

- Filter the logs by usage (scheduled actions, automation rules or server
  actions), by date, or on the ones with an error.
- Group them by action, usage, user or day.
- Use the pivot view to compare the number of executions and the durations of
  the actions, and the graph view to follow their duration over time.

Internal users can read and delete the logs. Only administrators can edit
them.
